# Документация курсового проекта

- `ЛаринИСП823_курсовой_проект.docx` — пояснительная записка (и `.pdf` для просмотра). На титульном листе и в задании жёлтым выделено место для имени и отчества студента.
- `diagrams/` — графическая часть в формате draw.io (`.drawio`, открываются в draw.io / app.diagrams.net) и их PNG, экспортированные draw.io:
  - `db` — диаграмма базы данных (Приложение 3);
  - `classes` — диаграмма классов (Приложение 1);
  - `states` — диаграмма состояний заказа (Приложение 2);
  - `flow` — общий алгоритм работы приложения, блок-схема (рис. 4).
- `screenshots/` — скриншоты приложения с эмулятора Android 14 (покупатель, продавец, администратор, тёмная тема); `screenshots/figures/` — рисунки 5–13 из записки.
- `tools/diagrams.py` — генератор схем draw.io.

Скриншоты и PNG схем пересоздаются workflow **UI screenshots** (Actions → UI screenshots → Run workflow), результат — в ветке `ui-screens`.
